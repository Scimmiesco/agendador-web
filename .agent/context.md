# Contexto do Projeto: Agendador Web

Este é um projeto web frontend para a aplicação "agendador", desenvolvido com as seguintes tecnologias principais:

## Tech Stack
- **Framework**: Angular 22
- **Linguagem**: TypeScript (~6.0)
- **Estilização**: Tailwind CSS v4 (com PostCSS)
- **Renderização**: Server-Side Rendering (SSR) configurado com Angular Universal/SSR e Express
- **Testes**: Vitest
- **Formatador**: Prettier
- **Gerenciador de Pacotes**: npm

## Estrutura e Scripts
- `npm start`: Inicia o servidor de desenvolvimento (`ng serve`).
- `npm run build`: Compila a aplicação para produção.
- `npm run test`: Executa a suíte de testes usando Vitest.
- `npm run serve:ssr:agendador`: Inicia o servidor SSR.

## Objetivos do Projeto
A aplicação serve como interface web do Agendador. O foco deve ser na performance, responsividade (utilizando Tailwind) e acessibilidade, aproveitando os recursos mais recentes do Angular (como standalone components, signals e control flow, se aplicável).
